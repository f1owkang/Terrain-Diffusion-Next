SEC 01 · Pipeline

How it works

How a tile of terrain is born

The real pipeline from the source code — every step runs deterministically from the world seed and config.

STEP 01

Diffusion sample

Three-stage diffusion outputs elevation + 4 climate channels, streamed tile by tile.

STEP 02

Terrain shaping

Folded-ridge noise builds the mountain skeleton; plateau mapping flattens tops, raises cliffs.

STEP 03

Biome pre-pass

Elevation + temperature/season/precip/precip-CV + slope resolve a first biome guess.

STEP 04

Wonders

Spires, calderas, mesas, pillar clusters, gorges — gated by biome, scattered deterministically.

STEP 05

River carving

D8 flow accumulation follows the real terrain, seamless across tiles, carved below sea level.

STEP 06

Final pass

Biomes recomputed: carved channels read as rivers, coastlines as beaches — heightmap out.

seed → terrain → shapes → biomes → wonders → rivers → world

SEC 02 · Features

Features

Core design

Every stage starts from the model output and lands as hand-written rules — the vanilla generator is never reused.

01 / Diffusion core

Diffusion terrain core

Coarse 20-step DPM-Solver++ → latent 2-step flow matching → 1-step decoder, emitting elevation + 4 climate channels; 64-tile cache, single inference thread keeps exploring responsive.

02 / Ridges · plateaus

Ridges & plateaus

Folded-ridge abs(noise) stacked by elevation for mountain skeletons; smoothstep-flattened plateau bands with steep cliff edges — Tectonic-style drama.

03 / Rare wonders

Rare wonders

Five landmark types gated by biome: taiga/peak spires, badlands calderas and gorges, desert pillar clusters, plains mesas — thresholds 0.96–0.985, genuinely rare finds.

04 / Real rivers

Terrain-following rivers

D8 flow direction + accumulation finds real paths; a 64-pixel halo window keeps them seamless across tiles; carved below sea level with tapered banks.

05 / Biome rules

40+ biome rules

Elevation + 4 climate channels + Sobel slope, judged pixel by pixel; coastline detection makes beaches, carved channels override to rivers.

06 / Explorer

Built-in terrain explorer

/td-explore starts a local web map: 6 channels (elevation / temperature / precip…), a coarse global view, and a seed preview for your next world.

SEC 04 · Quick start

Quick start

Quick start

Requires Fabric + Fabric API. The AI models (~2.5GB) download on first launch with automatic mirror failover; play offline afterwards.

01

Install the jar

Download the jar matching your Minecraft version from Releases and put it in your mods/ folder.

02

Launch & download

Launch the game once online — the AI models download into terrain-diffusion-models/ and are SHA-256 verified.

03

Create a world

Select the "Terrain Diffusion Next" world type. The seed determines everything.

04

Set World Scale

Click Customize and set the world scale (1..6), 2 recommended.

SEC 06 · FAQ

FAQ

Common issues

A dynamic link library (DLL) initialization routine failed

Older Java versions trigger this. Minecraft 26.x requires Java 25 or higher; the latest Microsoft OpenJDK 25 is known to work.

LoadLibrary failed with error 126 (CUDA build only)

Typically an improper CUDA or cuDNN installation — see the troubleshooting steps in CUDA_INSTALL.md.

Failed to load terrain-diffusion models

Usually an out-of-memory error. The models take up about 2.5GB of RAM — increase Minecraft's RAM allocation in your launcher.

01 · 生成流程

生成流程

一块地形是怎么生成的

六个环节，从世界种子到最终高度图，全程确定性执行。

STEP 01

扩散采样

三阶段扩散模型输出高程与 4 个气候通道，逐块流式生成。

STEP 02

地形塑形

折叠山脊的噪波搭建山体骨架，高原区域被压平、边缘拉起成悬崖。

STEP 03

群系预判

结合高程、温度、降水与坡度，先预估一遍群系分布。

STEP 04

奇观点缀

尖塔、火山口、桌山、石柱与峡谷，按群系门控随机落位。

STEP 05

河流雕刻

流向分析沿真实地形寻路，跨区块无缝衔接，海平面以下雕出蓄水河道。

STEP 06

收尾定稿

重算群系：河道变为河流、海岸变为海滩，输出最终高度图。

seed → terrain → shapes → biomes → wonders → rivers → world

02 · 核心特性

核心特性

核心设计

不套用原版生成器 —— 每个环节都从模型输出出发、以手写规则落笔。

01 / 扩散地形

扩散地形核心

20 步粗采样、2 步细采样、1 步解码，输出高程与 4 个气候通道；64 块缓存 + 单线程推理队列，边探索边生成不卡顿。

02 / 山脊高原

山脊与高原

折叠山脊按高程加权叠出山体骨架；高原内部被压平，边缘陡升如刀切 —— 参考 Tectonic 的戏剧性剖面。

03 / 稀有奇观

稀有奇观

五类地标按群系出现：针叶林尖塔、恶地火山口与峡谷、沙漠石柱、平原桌山 —— 出现概率不到 4%，可遇不可求。

04 / 真实河流

沿地形走的河流

流向与汇流分析沿真实地形寻路，跨区块无缝衔接；河道雕刻至海平面以下蓄水，河岸逐级渐变。

05 / 群系规则

40+ 生物群系规则

高程与四个气候通道结合坡度检测，逐像素判定；海岸带变为海滩、河道覆盖为河流。

06 / 地形探索

内置探索器

/td-explore 启动本地网页：6 通道地形分析图、全局地图，还能换种子预览下一个世界。

04 · 快速开始

快速开始

快速上手

Fabric + Fabric API。首次启动自动下载 AI 模型（约 2.5GB，多镜像自动切换），之后即可离线畅玩。

01

安装 Mod

从 Releases 下载与你的 Minecraft 版本匹配的 jar，放入 mods/ 文件夹。

02

下载模型

启动游戏（需在线一次），AI 模型自动下载至 terrain-diffusion-models/ 并做 SHA-256 校验。

03

创建世界

世界类型选择 「地形扩散」，世界种子决定一切地形。

04

世界尺度

点击 Customize 设置世界尺度（1..6），推荐 2。

05 · 版本选择

版本选择

该用哪个版本

除 macOS（自动 CoreML 加速）外，CPU 构建很慢 —— 推荐 Windows 或 CUDA 构建。

构建支持环境需要配置
Windows推荐 任意现代显卡的 Windows 无
CUDA NVIDIA 显卡 无需手动安装 —— 首次启动自动下载 CUDA 12 运行时
CPU 其他一切环境 无（Apple Silicon 自动 CoreML 加速）
版本 3.0.0-alpha Java 25 显存 1.5GB 内存 2.5GB MC 26.1 / 26.2 / 26.3

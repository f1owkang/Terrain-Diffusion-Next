How it works

一块地形是怎么生成的

从代码里读出来的真实管线：每一步都在世界种子与配置的驱动下确定性执行。

STEP 01

扩散采样

三阶段扩散模型输出高程与 4 个气候通道，按 tile 流式生成。

STEP 02

地形塑形

折叠山脊噪波搭建山地骨架，高原映射压平峰顶、拉起悬崖。

STEP 03

生物群系预判

高程 + 温度/季节/降水/降水变异 + 坡度，先算一遍群系。

STEP 04

奇观点缀

尖塔、火山口、桌山、石柱、峡谷——按生物群系门控随机落位。

STEP 05

河流雕刻

D8 汇流沿真实地形找路径，跨 tile 无缝，海平面下雕刻出蓄水河道。

STEP 06

最终定稿

重算生物群系：河道读作河流，海岸读作海滩，输出高度图。

seed → terrain → shapes → biomes → wonders → rivers → world

Features

核心设计

每个环节都从模型输出出发、以规则落笔 —— 不套用原版生成器。

01 / 扩散地形

扩散地形核心

coarse 20 步 DPM-Solver++ → latent 2 步 flow matching → decoder 1 步，输出高程 + 4 气候通道；64 个 tile 缓存、单线程推理队列，探索与生成互不阻塞。

02 / 山脊 · 高原

山脊与高原

折叠山脊（abs 噪波）按高程加权叠加出山地骨架；高原带内 smoothstep 压平、带外悬崖陡升——类 Tectonic 的戏剧性剖面。

03 / 稀有奇观

稀有奇观

五类地标按生物群系门控出现：针叶林尖塔、恶地火山口与峡谷、沙漠石柱、平原桌山；阈值 0.96~0.985，可遇不可求。

04 / 真实河流

沿地形走的河流

D8 流向 + 汇流累积找真实路径，64 像素 halo 窗口保证跨 tile 无缝；雕刻至海平面下蓄水，河岸逐级渐变。

05 / 生物群系规则

40+ 生物群系规则

高程 + 温度/季节温度/降水/降水变异四通道 + Sobel 坡度，逐像素判定；海岸带检测成海滩，河道覆盖为河流。

06 / 地形探索器

内置探索器

/td-explore 启动本地网页：高程/温度/降水等 6 通道分析图，coarse 全局地图，还能换种子预览下一张地图。

Quick start

快速开始

需要 Fabric + Fabric API。首次启动自动下载 AI 模型（约 2.5GB，多镜像自动切换），之后即可离线畅玩。

放入 mods

从 Releases 下载与你的 Minecraft 版本匹配的 jar，放入 mods/ 文件夹。

启动下载模型

启动游戏（需在线一次），AI 模型自动下载至 terrain-diffusion-models/ 并做 SHA-256 校验。

创建世界

世界类型选择 「地形扩散·Next」，世界种子决定一切地形。

设置 World Scale

点击 Customize 设置世界尺度（1..6），推荐 2。

Builds

选择哪个构建

除非你在 macOS 上，否则 CPU 构建很慢 —— Windows 或 CUDA 构建更推荐。

FAQ

常见问题

动态链接库（DLL）初始化例程失败

旧版 Java 会出现此问题。Minecraft 26.x 需要 Java 25 或更高版本，已知最新版 Microsoft OpenJDK 25 可用。

LoadLibrary failed with error 126（仅 CUDA 构建）

通常由 CUDA 或 cuDNN 安装不当导致，排查步骤见 CUDA_INSTALL.md。

Failed to load terrain-diffusion models

通常表示内存不足。模型约占 2.5GB 内存，请在启动器中调高 Minecraft 的内存分配。
